## 🛡️ Academic Projects

### [Security Consultation – Jones Café & Bakery](jones-cafe-security-consultation/) (2026)
Security assessment of a small business network before its website went live. I identified critical risks (end-of-life servers, a web server on the internal network and shared accounts) and recommended VLAN segmentation, firewall rules, MFA and patch management, plus AWS security controls (IAM, WAF, GuardDuty, CloudTrail, Inspector). The project ends with five Nmap scan types against a vulnerable lab machine.
**Tools:** Nmap, Kali Linux, Metasploitable2, AWS

### Vulnerability Assessment & Incident Response (2026)
Network and System Security module. I scanned and exploited vulnerable machines with Nmap, Nessus and Metasploit and documented the findings, wrote an incident response plan based on NIST SP 800-61, and reported on SQL injection (OWASP A03) with a Nikto web scan.
**Tools:** Nmap, Nessus, Metasploit, Nikto
